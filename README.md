# ✨ YADM config files

### 🐙 [YADM](https://thelocehiliosan.github.io/yadm)
**Yet another dotfiles manager**
> 💾 Simple tool to store your dotfiles on GitHub

## 🚀 Usage

### 🖥️ Clone on a brand new machine
```bash
yadm clone git@github.com:marek2901/config_files.git
```

### ➕ Add new files
```bash
yadm add .filerc
yadm commit -am "added filerc"
yadm push origin master
```

### 💾 Save changes
```bash
yadm commit -am "modified file filerc added bla bla"
yadm push origin master
```
